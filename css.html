Introducción

Hojas de estilo en cascada, es lenguaje que define la presentación visual de los documentos estructurados de HTML, la anatomía de una regla de CSS, cosnta de tres partes:

  1. Selector: indica que elementos (h1, p, button), se le aplicara el estilo por ejemplo .tarjeta (class="tarjet"), #tarjeta (id="tarjeta").
  2. Propiedad: El atributo visual que deseas modificar (color, color de fondo, font-size).
  3. Valor: La configuración específica que le asignas.

Box Model

Todo elementos renderizado en el navegador es una caja rectangular compuesta por 4 capas (de adentro hacia afuera):

  1. Content: El área donde, habita el texto, imagen o elementos hijos.
  2. Padding: Espacio transparente interno entre el contenido y el borde.
  3. Border: La linea que rodea el relleno y el contenido.
  4. Margin: Espacio transparente externo que separa esta caja de las vecinas
  5. Box-sizing y Border-box: Propiedad de oro de la industria, asegura que el ancho widht y el alto height, que les des a un elemento incluyan el padding, y el border, evitando que la caja "se rompa" o se vuelva más grande de lo calculado.

CSS FLEXBOX

Flexbox es un modelo de diseño unidimensional diseñado para distribuir espacio y alinear elementos a lo largo de un eje. Para activar FLexbox, se aplica la propiedad "display: flex;" al elemento padre llamado Flex Container, a partir de ese momentos, todos sus hijos directos se convierten en Flex Items.

Ejes de Flexbox

  • Eje principal(Main Axis): Dirección por defecto en la que se colocan los elementos de izquierda a derecha.
  • Eje transversal (Cross Axis): Dirección perpendicular al eje principal de arriba a abajo.

Propiedades Clave del Contenedor Padre

  • flex-direction: Defiene la dirección del eje principal (row) por defecto, column, row-reverse, column-reverse.
  • justify-content: Alinea los elementos a lo largo del eje principal, flex-start, center, flex-end.
    space-between (separa los extremos y distribuye el espacio al centro).
    space-around y space-evenly (distribuye el espacio equitativamente).
  • align-items: Alinea los elementos a lo largo del eje transversal, center, flex-start, flex-end, stretch.
  • gap: Define la distancia de separación exacta entre los elementos hijos, evitando usar margenes individuales.
  • flex-wrap: Controla si los elementos pasan a la siguiente línea cuando no caben en la pantalla (nowrap, wrap).

CSS Grid

Imagina que tienes una hoja de cuaderno cuadriculada, con flexbox, colocas los objetos de otro como una fila de piezas de dominó, con CSS grid, dibujas una cuadrícula fija con filas y columnas, tu decides cuántas columnas tiene la mesa y en que casilla exacta o cuantas casillas juntas, se va a acomodar cada objeto, es como armar un rompecabezas o una pagina de revistas.


Para activar CSS grid aplicamos la propiedad "display: grid;"

  1. Definición de columnas y Filas: grid-template-columns define el número y ancho de las columnas.
    • grid-template-columns: 200 px 1fr 1fr (crea 3 columnas, una fija de 200 px y dos que se reparten el espacio restante).
    • grid-template-columns: repeat (3, 1fr). (crea 3 columnas de idéntico tamaño)
    • grid-template-rows: define la altura de las filas.

  2. La unidad fr (Fractional Unit): Es una unidad exclusiva de CSS grid que representa una fracción del espacio libre disponible en el contenedor. 1fr 2fr significa que la segunda columna será el doble de grande que la primera.

  3. Separación(gap): Ya sea (gap: 20px;) o row-gap y column-gap establece la distancia exacta entre las casillas de la cuadrícula.

  4. Abarcar multiples celdas (Spanning): En los elementos hijos podemos usar grid-column: span 2; o grid-row: span 2; para que una tarjeta ocupe el ancho/alto de dos o más casillas.

  5. Rejilla Responsiva Autómatica (auto-fit, auto-fill + minmax): grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); Esta es una regla más potente de CSS moderno, crea columnas automáticas que miden al menos 250px, y se adaptan solas al tamaño de la pantalla sin necesida de escribir código extra.

Así como en Flexbox, grid tiene propiedades para alinear los elementos, pero aquí hay un detalle mportante: grid maneja dos tipos de alineación:


  • Alinear los elementos dentro de sus celdas: Se logra con justify-items, align-items.
  • Alinear toda la cuadricula dentro del contenedor: Se logra con justify-content, align-content.

Propiedades para alinear los items dentro de sus celdas

Propiedad Que hace? Valores comunes
justify-items Aline los items horizontalmente dentro de su celda start, center, end y stretch
align-items Alinea los items verticalmente dentro de su celda start, center, end y strecth
place-items Atajo para ambos center center
Propiedad Que hace?
Justify-content Alinea la cuadrícula horizontalmente en el contenedor
align-content Alinea la cuadrícula verticalmente en el contenedor
place-content Atajo para ambos

Ejemplos Practicos

Grid-auto-flow

Cuando no defines explícitamente donde va cada elemento, Grid los coloca automatícamente en filas, pero puede cambiar ese comportamiento.

Dense es muy util cuano tienes elementos de diferentes tamaños y quieres evitar espacios vacíos

Grid-auto-rows y grid-auto-columns

Cuando creas más filas o columnas de las que definiste, grid las crea automáticamente, estas propiedades controlas su tamaño.

Grid-template-areas

Es tan poderoso que merece su propio sección

Reglas

  • Cada string es una fila
  • Repetir un nombre hace que el elementos abarque varias celdas
  • Un punto (.) deja un celda vacia
  • El área debe ser un rectángulo perfecto (no puede tener forma de L)

Min-content, max-content y fit-content

Unidades especiales que se adaptan al contenido

Reglas

  • Min-content: El ancho mínimo que necesita el contenido sin romper palabras
  • Max-content: El ancho máximo que necesita el contenido sin cortar nada
  • Fit-content(200px): Se ajusta al contenido pero sin pasar de 200px

Grid-column y grid-row

También se puede usar número de línea, las líneas son las divisiones entre celdas, si tienes 3 columnas hay 4 lineas (una antes de la primera, 3 entre ellas y una despues de la última).

Diseño Responsivo y Media Queries

Imagina que compras un traje mágico de superhéroe, si estas en un pasillo muy estrecho (un telefono celular), el traje se encoge, guarda las herramientas en una sola fila hacia abajo y oculta los adornos gigantes para que no choques con las paredes.
Si entras a un gimnasio enorme (un monitor de computadora), el traje se despliega, muestra todas sus bolsas, en 3 o 4 columnas una al lado de la otra y agranda la letra para que todo se vea genial desde lejos.

Medias Queries (@media)

Son los sensores de ese traje mágico, le dicen a la pagina web "Mide la pantalla", si es más angosta que ceirto tamaño, cambia los colores la letra y el diseño para que se vea perfecta.

Profundización Técnica

  • El Meta Tag Viewport (indispensable): Sin esta línea en el "head" de tu HTMl, los telefonos móviles simularán una pantalla de escritorio gigante y encogerán toda la página como si fuera una miniatura ilegible.
  • Sintaxis de las Medias Queries (@media): Son bloques condicionales que se activan únicamente cuando la pantalla cumple cierto rango de ancho

Estrategia Mobile-First vs Desktop-First

  • Desktop-First: Escribes el CSS pensado para computadoras y agregas @media (max-width: 768px), para reducir o acomodar en pantallas pequeñas.
  • Mobile-First (Estandár de la Industria): Escribes el CSS base pensando en pantallas pequeñas y usas @media (min-width: 768px), para expandir y añadir columnas a medida que la pantalla se hace más grande

Puntos de Interrupción (Breakpoints)

  • 640px: Teléfonos en modo horizontal o móviles grandes.
  • 768px: Tablets.
  • 1024px: Laptops, computadoras de escritorio.
  • 1280px: Pantallas anchas de alta resolución.

Variables CSS Animaciones y Transiciones

Variables CSS

Imagina que estás pintando una maqueta gigante, en lugar de buscar bote por bode cada vez, que quieras pintar un muro de azul, creas un botón mágico en tu paleta llamado "AzulMarca", si algun día decides que el color ya no sea azul sino verde, solo cambias el color del botón mágico y toda tu maqueta cambia de color automáticamente al mismo tiempo

  • Declaración: Se definen con dos guiones (--), al inicio habitualmente se colocan dentro de ":root" para que estén disponibles en todo el documento.
  • Uso: Se invocan mediante la función var(--nombre-variable).

Transiciones y Animaciones

Es la diferencia entre la teletransportación y caminar, sin transiciones, un botón cambia de color de golpe, con transiciones el botón se ilumina suavemente.
Las animaciones son como crear tus propios dibujos animados (Flipbooks), para que las luces parpadeen o los íconos giren mientras se procesa un estudio.

  • Sintaxis Resumida: transition: [propiedad] [duración] [función-de-tiempo];
